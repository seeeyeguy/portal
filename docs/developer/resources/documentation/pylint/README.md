# Pylint

## Description:
Pylint is a static code analyzer that reviews your code without actually running it. It can check for errors, enforces a coding standard (which can be configured), and can even make suggestions on how to refactor existing code.

## Documentation:
For more details on Pylint, please refer to the [official documentation](https://pylint.readthedocs.io/en/latest/user_guide/installation/index.html).

## How to run:
 
1. Run the command: `pylint api/src --rcfile api/.pylintrc`
